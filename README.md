# Memories - Gallery App

## About

Memories is a privacy-first Android gallery. It builds memories, search, and home screen widgets from your photos entirely on your phone. The app has no internet permission and no cloud features.

## Privacy design

To be written. It will explain how the app keeps every photo and every result on the device.

## Building

Requirements: JDK 17 and the Android SDK (Android Studio installs it).

```
./gradlew :app:assembleDebug
```

The debug APK is written to `app/build/outputs/apk/debug/`.
